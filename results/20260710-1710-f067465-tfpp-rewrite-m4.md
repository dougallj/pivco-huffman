# tail-free-ping-pong-rewrite — M4 A/B (2026-07-10)

Save/restore-guard design vs the ceilq end-invariant design vs
upstream ping-pong.  `bench 20 --all`, best-of-2 for the rewrite,
single runs for the references (same session, interleaved).

| comparison                        | geomean |
|-----------------------------------|---------|
| rewrite vs ping-pong              | +2.7 %  |
| rewrite vs tail-free-ping-pong    | +1.4 %  |
| rewrite unaligned/aligned (--blk) | −2.7 % (single pair; old slab cliff was −10.7 %) |

The rewrite keeps upstream ping-pong's placement VERBATIM and instead
wraps each NEON decode prim in a save/restore guard (load 16 B at
out+K, run the tail-free kernel, store them back) — every scratch
write becomes exact, so prefix partners, in-place children and the
arena bound need no special handling.  Aligned calls skip the guard
(required at the root, which targets the caller's `symbols`); the
unaligned root keeps the exact-tail epilogue.  Codec churn is ~half
the invariant branch's, and rows like bell_s10 (+7.0 %) and
csv_numeric (+5.5 %) suggest the removed placement arithmetic was
costing real time.  dna_fasta −4.6 % / flat_M6 −2.3 % vs tf-pp are
single-run wobbles worth rechecking if this becomes the keeper.

GuardMalloc earned its keep: the first cut's D==8 flat-root shortcut
called a guarded prim on `symbols` (transient touch past N) and was
caught immediately.  Raw captures: m4-*-tfpp-rewrite-f067465.txt,
m4-*-ppbase3-88849e0.txt (+ rw_* in session scratch).
